# NOW / IRL — Safe Migration & Codebase Rebuild Plan

**Цель:** Безопасный переход с кодовой базы MoodCall на новую доменную модель NOW / IRL без потери работающей инфраструктуры и с гарантией полного отката (Rollback Safety).  
**Версия документа:** 2.0.0 (Phase 0)  

---

## 1. Стратегия резервного копирования перед изменениями

Поскольку в текущем окружении утилита `git` не установлена глобально в PATH, для гарантированной сохранности результатов Среза 1 создается файловый изолированный снимок:

1. **Создание архива `_archive_moodcall_v1/`:**  
   Перед началом удаления старого кода все файлы схемы Среза 1, миграция `0000_wet_wallow.sql` и старые тесты копируются в каталог `_archive_moodcall_v1/`.
2. **Изоляция миграций:**  
   Файлы `0000_wet_wallow.sql` и `0000_wet_wallow.down.sql` переносятся в `src/db/migrations/archive/`, исключая их случайное повторное применение к базе данных.
3. **Безопасность базы данных:**  
   Никакие деструктивные команды `DROP DATABASE` не выполняются. Миграция создается как чистый SQL-файл для новой структуры таблиц.

## 2. Матрица трансформации доменной модели (Domain Entity Mapping)

## 3. Ревизия файлов кодовой базы (File Inventory)

### 3.1. Файлы, которые переиспользуются без изменений или с минимальными правками:
- `package.json`, `tsconfig.json`, `tailwind.config.ts`, `postcss.config.js`, `.eslintrc.json`, `vitest.config.ts`, `playwright.config.ts`;
- `src/lib/logger.ts` — Zero-PII структурированный логгер со строгим denylist;
- `src/lib/env.ts` — Zod-валидация переменных окружения;
- `src/db/index.ts` — пул соединений PostgreSQL;
- `.env.example`, `.gitignore`.

### 3.2. Файлы, подлежащие полной переработке:
- `src/db/schema/enums.ts` — удаление `payment_status`, замена `booking_status` на `meetup_status` и `participant_status`;
- `src/db/schema/tables.ts` — замена 19 таблиц на новую схему NOW / IRL;
- `src/db/seed.ts` — наполнение каталога типами активностей (`activity_types`), интересами (`interests`), демо-зонами и тестовыми митапами-огоньками;
- `src/app/page.tsx` — переработка под интерфейс «Огоньки рядом» и кнопка «Собрать компанию»;
- `src/app/layout.tsx` — замена названия на NOW / IRL, обновление метаданных;
- `README.md` — обновление под концепцию спонтанных групповых встреч.

## 4. План отката (Rollback Procedure)

При необходимости вернуть исходный код MoodCall:
1. Восстановить файлы из директории `_archive_moodcall_v1/`;
2. Переместить архивные миграции из `src/db/migrations/archive/` обратно в `src/db/migrations/`;
3. Запустить `npm run check`.
