# NOW / IRL — Spontaneous Offline Group Activity Coordinator (MVP Prototype)

> [!CAUTION]
> **DEMO ONLY — SPONTANEOUS GROUP MEETUP PROTOTYPE — NOT FOR REAL EMERGENCIES**  
> Этот проект является демонстрационным прототипом (MVP) координатора офлайн-активностей.  
> Все локации в базе представлены вымышленными нейтральными демонстрационными зонами (`DEMO_PUBLIC_ZONE_1..3`).  
> Все «Огоньки» и пользователи в сид-данных являются синтетическими сущностями (`is_demo = true`).  
> В прототипе отключена реальная диспетчеризация экстренных служб: кнопка SOS выводит прямую ссылку на `tel:112` и инструкции безопасности.

---

## 1. О продукте NOW / IRL

**NOW / IRL** — спонтанный координатор офлайн-активностей для верифицированных взрослых 18+ в проверенных публичных зонах (кофе, прогулки, настольные игры, футбол, воркаут, просмотр матчей/UFC).

### Ключевая механика: «Огонёк» (Live Pulse)
- **Anonymous Discovery:** на интерактивной псевдокарте и в ленте отображаются не люди, а анонимные импульсы активности.
- **Минимизация геоданных:** вместо точных GPS отображаются диапазоны («до 500 м», «до 1 км»).
- **Анонимность до встречи:** до момента вступления в «Огонёк» видны только категория активности, таймер до старта, лимит мест (`3/4`), возрастной диапазон участников (`18-21`, `22-25`) и рейтинг надежности (без лиц и личных профилей).
- **Anti-goals:** сервис категорически **НЕ** является дейтингом, сервисом знакомств или эскортом. Полное отсутствие приватных комнат 1-на-1 и денежных расчетов между участниками.

## 2. Быстрый запуск

```bash
# 1. Запуск сервера разработки
npm run dev
```

Приложение будет доступно по адресу: [http://localhost:3000](http://localhost:3000)

---

## 3. Установка и подготовка базы данных

### 3.1. Установка зависимостей
```bash
npm install
```

### 3.2. Переменные окружения
Скопируйте шаблон конфигурации:
```bash
cp .env.example .env
```
Укажите строку подключения к каноническому PostgreSQL 15+ в переменной `DATABASE_URL`.

### 3.3. Генерация и применение миграций
```bash
# Генерация SQL-миграции Drizzle (19 таблиц NOW / IRL)
npm run db:generate

# Применение миграции к PostgreSQL
npm run db:migrate
```

### 3.4. Заполнение демонстрационными «Огоньками» (Seed)
```bash
npm run db:seed
```
*Защита:* Запуск сида аппаратно заблокирован при `NODE_ENV=production`.

## 4. Фоновые задачи (Workers)

```bash
# Очистка чатов митапов старше 12 часов (Ephemeral retention policy)
npm run purge:chats

# Авто-отмена просроченных митапов при недоборе кворума
npm run meetups:expire
```

## 5. Проверка качества и тестирование
