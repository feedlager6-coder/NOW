# NOW / IRL — Data Protection, Privacy & Retention Policy

**Версия документа:** 2.0.0 (Phase 0 — Group Activity Privacy Framework)  
**Статус:** Draft for Review / Pre-Implementation  
**Принципы:** Data Minimization, Privacy-by-Default, Ephemeral by Design  

---

## 1. Анонимное обнаружение (Anonymous Discovery Architecture)

Фундаментальный принцип NOW / IRL: **нельзя искать конкретных людей, можно находить только активности**.

### 1.1. До момента присоединения к митапу (Pre-Join Privacy):
- Ни один пользователь не может увидеть реальное имя, фамилию, аватарку с лицом, телефон или профиль в соцсетях других участников;
- В карточке активности отображаются строго анонимизированные агрегаты:
  - Силуэт / абстрактный геометрический аватар (placeholder);
  - Возрастная когорта (например, `22–25` вместо точной даты рождения);
  - Список интересов (например, `[футбол, настолки]`);
  - Индекс надежности (Reliability Badge: например, «3 завершенные встречи без опозданий», если пользователь включил эту опцию в настройках приватности);
- Точные GPS-координаты скрыты: отображаются только название демонстрационной зоны из whitelist и дистанционный диапазон (Distance Band: «до 1 км», «1–3 км»).

### 1.2. После подтверждения участия (Post-Join Privacy):
- Участникам открывается `display_name` (псевдоним) и доступ к одноразовому групповому чату активности;
- Телефонные номера и персональные профили остаются скрытыми.

## 2. График хранения и удаления данных (Data Retention Schedule)

| Категория данных | Срок хранения | Действие по истечении срока | Исключения (Safety Exception) |
| :--- | :--- | :--- | :--- |
| **Сообщения группового чата (`meetup_messages`)** | **12 часов** после завершения/отмены митапа | Полное безвозвратное удаление текста из активной базы данных (Soft Delete / Hard Purge) | Если по митапу открыт инцидент безопасности (`safety_events`) или жалоба P0 (`reports`), фрагменты сообщений архивируются в изолированный аудит-лог для разрешения инцидента. |
| **Временные геокоординаты митапа** | **12 часов** после завершения | Зануление полей (`approximate_lat = NULL`, `approximate_lng = NULL`) | Нет исключений. |
| **Сессии пользователей (`sessions`)** | 30 дней | Принудительный отзыв токена (`revoked_at = NOW()`) | — |
| **Временные OTP-коды** | 5 минут | Удаление из временной памяти | — |
| **Юридические согласия (`consents`)** | 5 лет | Архивирование | Требование ст. 9 152-ФЗ и срока исковой давности |
| **Логи безопасности (`safety_events`, `reports`)** | 3 года | Неизменяемый структурированный лог | Юридическая защита пользователей и платформы |

> [!NOTE]
> **Честное информирование пользователей:**  
> Платформа открыто заявляет в Политике конфиденциальности, что чаты автоматически удаляются через 12 часов, однако при возникновении правонарушений или вызове Safety Help переписка фиксируется для передачи правоохранительным органам по официальному запросу.

## 3. Криптографическая защита учетных данных

1. **Хэширование телефонных номеров (`phone_lookup_hash`):**
   - Номера телефонов не сохраняются в открытом виде;
   - Для поиска аккаунта используется `HMAC-SHA256(normalized_phone, OTP_HMAC_SECRET)`;
   - В DEMO MODE используются исключительно вымышленные синтетические номера (`+70000000001` и т.п.);
   - Реальный номер для SMS-доставки (при внедрении) будет сохраняться отдельно и строго в зашифрованном виде через абстракцию SMS-провайдера.
2. **Нулевой сбор биометрии:**
   - Категорический запрет на загрузку паспортов, селфи с документами и биометрических слепков лица.

---

## 4. Протокол удаления учетной записи (`DELETE /api/me`)

1. **Блокировка удаления при активных митапах:** Если пользователь является создателем митапа в статусе `gathering` или `active`, либо активным участником встречи, удаление отклоняется до завершения или выхода из митапа (`CANNOT_DELETE_WITH_ACTIVE_MEETUPS`).
2. **Процесс анонимизации:**
   - В таблице `users`: `deleted_at = NOW()`, `phone_lookup_hash` заменяется на необратимый tombstone UUID;
   - В таблице `profiles`: `display_name = "Бывший участник"`, `bio = NULL`, `avatar_ref = NULL`;
   - В таблице `sessions`: все сессионные токены отзываются (`revoked_at = NOW()`);
   - В таблице `meetup_participants`: статус меняется на `left`.
